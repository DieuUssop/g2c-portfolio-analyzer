# Exports de courtiers — fichiers FICTIFS

Ces fichiers imitent la disposition des exports CSV de cinq courtiers (DEGIRO, Fortuneo,
Bourse Direct, Boursorama, Trade Republic) : noms et ordre des colonnes, séparateurs, format
des dates et des nombres. Les opérations, montants et identifiants d'ordre sont inventés ; aucun
vrai relevé n'est utilisé. Les colonnes réelles peuvent varier d'une version à l'autre des sites :
si un vrai export n'est pas reconnu, l'assistant d'import s'ouvre (et un nouveau fichier fictif
reproduisant sa disposition doit être ajouté ici, avec son test).
